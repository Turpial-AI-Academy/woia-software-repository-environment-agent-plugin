# Assets

These files are starting points for repositories that deliberately select the corresponding Mise profile.

- `mise.node-pnpm.template.toml` — Node + pnpm profile.
- `mise.bun.template.toml` — Bun profile.

Do not copy either asset blindly. First inspect the target repository, preserve healthy existing standards, replace example versions/tasks with the repository's actual contract, and omit irrelevant tasks/tools.
